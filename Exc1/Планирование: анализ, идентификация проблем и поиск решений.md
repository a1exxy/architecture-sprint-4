# 1. Планирование: анализ, идентификация проблем и поиск решений

## Проблемы

- потеря/задержка заказов B2C (Публичный магазин)
- потеря/задержка заказов B2B (Публичное API)
- долгая загрузка дашборда MES
- только ручное e2e тестироывание - будет увеличивать время релизов
- публикация технологического api MES в обход CRM
- отсутсвует мониторинг
- отсутвует логинг
- отсутсвует возможность прослеживания запросов пользователей и выявление потерь/задержек
- отсутвие балансировщика запросов
- отсутсвие кэширования
- общая база у CRM и магазина
- отсутсвие возможности загрузки 3D моделей через публичное API

## Решения

- Добавить мониторинг, логгинг, трейсинг
- Добавить api gateway + service discovery
- Создать crm db для сервиса crm api
- Обеспечить интеграцию shop api и crm api через брокер очередей (для формирования заказов в CRM из магазина и публичного api)
- Создать BFF для shop api что бы подключить приложение Shop и B2B партнеров (API)
- Добавить реплику к shop db для отделения операций чтения
- Разделить shop api на два: для операций чтения и для операций записи
- Добавить кэш для shop api
- Добавить реплику к crm db для отделения операций чтения
- Добавить кэш для mes (отображение дашборда)
- На mes api реализовать передачу заказов на GUI MES через протокол Websocket (что бы убрать повторную передачу информации)
- Добавить среду staging для автоматизированного e2e тестирования
- Увеличение количества инстансов shop api
- Увеличение количества инстансов crm api
- Увеличение количества инстансов mes api
- Добавить реплику к mes db для отделения операций чтения

## Целевая архитиктура через полгода

За пол года нужно реализовать первые 5 пунктов, это позволит полностью контроллировать все заказы.
Остальные пункты необходимо реализовывать в зависимости актуальности оставшихся проблем.

## Приоритезация

Если есть возможность выполнить только 3 пункта, то максимальный эффект должны дать пункты:

- Добавить мониторинг, логгинг, трейсинг
- Добавить api gateway + service discovery
- Создать BFF для shop api что бы подключить GUI Shop и B2B партнеров (API)

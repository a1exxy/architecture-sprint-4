# 2. Выбор и настройка мониторинга в системе

## Мотивация

- Мониторинг даст возможность контроллировать бизнес метрики и максимально быстро, до того как заметят пользователи реагировать на проблемы, это улучшит пользовательский опыт.
- Полноценные метрики позволят предсказывать и предотващать отказы системы.
- Без метрик локализация проблемы будет затруднена или не возможна, что может привести к долговременному прерыванию или гибили бизнеса.
- Наличее метрик позволит производить контролируемое изменение версий ПО и в случае неудачи производить откат.

- CPU % for shop API - работоспособность сервиса
- Memory Utilisation for shop API  - работоспособность сервиса
- Number of requests (RPS) for internet shop API - нагрузка
- Number of requests (RPS) per user for internet shop API - нагрузка
- Response time (latency) for shop API - отказ сервиса
- Number of HTTP 200 for shop API - успешные ответы
- Number of HTTP 500 for shop API - ошибочные ответы
- Number of simultanious sessions for shop API - сбой
- Kb tranferred (received) for shop API - объем
- Kb provided (sent) for shop API - объем
